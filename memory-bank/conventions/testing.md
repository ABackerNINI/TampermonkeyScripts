# 测试与可测性约定
> 摘要: 易测代码设计与零依赖 tests 布局, 禁留测试后门, 禁为过测改生产, 换肤未知元素安全断言
> 触发: 写测试, 跑测试, 设计可测性

## 8. 测试与可测性约定

### 8.1 鼓励设计易测试的代码

- 允许并鼓励为可测试性设计：逻辑尽量纯函数化（输入数据 → 输出数据，如 `parseTorrentTable`）、配置与逻辑分离、副作用收敛到 `main()` 等入口、可注入数据源/时钟等。
- 本地回归脚本/断言**统一放在 `tests/`**（不放 `src/`，避免与生产脚本混放）：按被测脚本分子目录 `tests/<脚本名>/*.js`，每个文件 = 一个可独立运行的测试，以退出码表达结果（如 `tests/ptautocheckin/`）；`node tests/run-all.js` **递归**跑完全部（新增脚本目录无需改运行器）。共享基建 `tests/lib/`（含 `lib/sim` 仿真站）与数据 `tests/fixtures/` 不被当作测试执行。
- **零依赖**：只用 Node 内置模块，不引入任何 npm 包/测试框架（与本仓库「无 package.json / 无构建」一致）。
- 测试约定与「如何测 userscript」（把源文件里自包含的代码块切出来写进临时模块再 `require`）见 `tests/README.md`。

### 8.2 禁止为测试专门留通道

- **不得**在生产代码中留仅测试使用的后门/钩子，例如：
  - `if (window.__TEST__) {...}` 之类的全局开关；
  - 为测试把内部函数挂到 `window`；
  - 通过 URL 参数/查询串开启测试模式；
  - 为断言方便而额外暴露本不需要的 DOM 标记。
- 需要测试内部逻辑时，应通过**重构为可独立调用的纯函数/参数注入**实现（见 8.1），而不是污染生产路径。

### 8.3 禁止为了测试通过而修改生产代码

- 测试失败先排查：**测试自身**（断言/样本/环境）是否有误 → 生产代码是否存在**真实缺陷**；
- 不得为了让测试变绿而：弱化/删除断言、跳过分支、写死返回值、或让生产代码迎合测试期望；
- 修改生产代码必须以「修复真实问题 / 符合真实行为」为前提；若测试与真实行为冲突，**以真实行为为准**并修正测试。

### 8.4 换肤类脚本：未知元素安全断言（deny-by-default）

纯 CSS 换肤脚本（HDHomeUI）的既有测试容易**全是正向断言**（骨架特征存在 / 已知元素画得对 / 已知功能还在），
却没人问"页面上那些**我不认识**的东西还在不在"。补这类断言时遵守：

1. **「没被屏蔽」不等于 display 不是 none**。屏蔽有四类隐蔽写法（P66）：
   清掉 `background-image` 不补 content（变空白）、只压深背景不管**写死的前景色**（黑字黑底＝隐形）、
   `overflow` 裁切、`z-index` 压住 / `contain` 改定位基准。**元素都还在，矩形都非零**。
2. **判据必须三道叠加**，只看"存在 + 矩形非零"抓不到：
   - **hit-test 命中自身**（`document.elementFromPoint` 防被裁/被压/跑出视口）
   - **对比度 Δ≥40**（取 20 会让"纯黑字压在深色片基上"蒙混过关 —— 实测亮度差正好 22）
   - **图标 content / background 至少一层是内联 SVG**（防"非空但仍是站点雪碧图"）
3. **隐藏类声明走白名单**：`display:none` 之类只有在白名单内才允许，且每条必须写理由；
   新增一条隐藏声明而不补白名单 ⇒ CI 红。作用域同样要钉死：每条规则的选择器必须锚定已知根。
4. **反例必跑**：写完全部断言后，逐条把对应的生产兜底删掉，确认断言真的会变红再改回来。
   （本轮 11 条反例里 2 条一开始是绿的 —— 判据太松，就是靠反例发现的。）
5. **未知结构不猜**：认不出来的列 / 行 ⇒ 整体不上妆，而不是硬着头皮排版（P69）。
6. **本地全绿 ≠ 判据稳**（P70）：Windows 与 CI 的 ubuntu 在**字体度量与可滚动高度**上不同，
   几何/hit-test 类断言必须靠 CI 交叉验证。CI 红而本地绿时，先怀疑"依赖滚动 / 依赖字体"的断言。
   两条硬规矩：① 自己注入的多个浮层位置要互相岔开，**视口正中（scrollIntoView 的落点）不许有 fixed 浮层**；
   ② hit-test 类断言要先断言前置状态成立（如 `scrollY === 600`），否则会出现"看起来验了、其实没验"的假绿。
