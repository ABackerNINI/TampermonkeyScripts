# FAB / 面板 UI
> 摘要: 跨站 FAB 角标、皮肤与动效开关、结果面板、失焦自动关闭与按钮重现警示的 UI 行为
> 触发: 改 FAB 皮肤/动效, 改面板交互, 排查面板误弹

## FAB / 面板 UI

- Shadow DOM 注入, 样式完全隔离; CSS 变量 + `@media (prefers-color-scheme: dark)` **跟随系统深浅色**。
- **主面板「失焦自动关闭」(2026.09.19.4, 用户需求)**: 面板是用完即走的浮层 —— 焦点离开即收起:
  ① 点面板外任一处(`document` **捕获阶段** `mousedown`, 抢在站点 `stopPropagation` 之前);
  ② 切标签页/切窗口/点地址栏(`window` 的 `blur`)。三条配套约束:
  · **监听只在面板展开期间挂**(`openPanel` → `armAutoClose`, `closePanel` → `disarmAutoClose`), 不给宿主页面留常驻全局监听;
  · **点在 UI 自身不算失焦** —— shadow(closed) 内部事件传播到外部时 `target` 被重定向成 `host`, 故用 `host.contains(e.target)` 判定(否则点面板里的「批量签到/外观」会把自己关掉);
  · **操作钮横幅机制已随断点续签移除(2026.11.16)**: `showBanner` 已收缩为 `(msg, variant)`, 横幅不再有操作钮 —— **自动收起一律收起**(点面板外/失焦无豁免)。
  · **C4 边界(2026.11.24.4, 靠边模式)**: 面板打开期间即使指针移出, FAB 仍**保持展开不缩回**; 批量进行中(`batchActive()`)也强制保持展开; 只有「面板已关闭 且 指针离开命中区」才缩回竖线。失焦自动关闭链(`blur` → `closePanel`)照旧生效, 不改变上述展开判定。
  ⚠️ 因此**程序性弹出的面板要意识到它会被收起**: 目前仅 `showBatchDone`(批量完成)一处, 横幅无操作钮 → 可被收起; 新增自动弹面板的场景先想清楚"被误关了用户还能不能找回入口"。
- **重现提醒不弹主面板(2026.09.19.4)**: 「签到按钮重现」的页面级呈现**唯一入口** = `presentReappearedOnPage(unit, toastMsg)`(按钮琥珀描边 + ⚠ 徽标 + 底部横条 + 首次降级一条琥珀 toast; `toastMsg` 空串 = 只重建装饰不打扰)。**该入口与复核分支内均不得出现 `openPanel`** —— 用户正在看页面上的签到按钮时把面板弹出来 = 抢焦点 + 挡住要看的东西; 面板内本就有常驻警示条与行标记, 想看随时点 FAB。两条不变式由 `tests/ptautocheckin/check-ptac-panel.js` 静态钉死, 并由 `tests/ptautocheckin/sim-panel-autoclose.js` 在真浏览器里实测 —— 面板挂在 closed shadow 下, 页面脚本/CDP 都拿不到 `panel` 元素, 故用 `document.elementFromPoint` 的 **shadow 重定向**(命中面板 → 返回宿主 `#ptac-root-v2`)判定开合(详见校准项 23; 靠边模式 C4 六场景另见 `calibration-detail.md` 校准项 23 的 C4 段, W4 已补一条实测)。已实测通过: 点面板外收起 / 点 UI 自身不收起 / window blur 收起 / 重现不弹面板且零点击。
- FAB(右下角, 渐变圆钮)→ 点击展开面板：今日汇总 + 分组列表(多吧 group 有组头)+ 每行状态徽章/msg/时间 + 「批量签到(剩余 n)」按钮。**FAB 皮肤 2 套可切换**(面板头部「外观」展开选择条, 存 `ptac_skin` 跨站生效): ①**变色**(默认) 全完成→绿底✓(无角标)/ 有未签→紫底✓+红底剩余角标(辉光呼吸与变色形变均走合成器友好写法: 预渲染光晕伪元素只动 `opacity` / 形变只留 `transform`, 静息不再逐帧 Recalculate Style); ②**信号灯** 完成→绿✓ / 今日有失败→红底!+失败角标 / 其余→琥珀✓+剩余角标。**legacy 内存归一**: 老用户 `ptac_skin=static|number|ring` 在 `applyFabSkin` 入口**局部归一为变色**(渲染 + 皮肤条 active 高亮一致), GM 存储值**原样保留、不回写**(静默回退, 不写迁移持久化代码); 静态(static)/数字(number)/光环(ring)三套皮肤及其 `numPulse`/`ringBreathe`/`rayPulse`/`.ring-rays`/`--ring-grad`/`.fab.static` 实现已**全部删除**。核心诉求: **全部签到完毕与有站点未签到在 FAB 上有明显区别**。
- **FAB 动效开关(2026.11.24.5, 与皮肤/靠边正交)**: 皮肤条内加独立布尔开关 `data-motion`(文案「动效」/「静态」, 与靠边开关并列、细分隔线隔开), 存 GM 键 `ptac_motion` **跨站生效**; 关动效 = host 挂 `.motion-off`, shadow 内用 `:host(.motion-off) .fab` / `.fab::after` / `.fab.chameleon` 三条规则 `animation:none!important` 停掉本体形变/辉光呼吸/变色形变, **状态色与角标不变**; `ptacHlPulse`(签到按钮高亮)属签到逻辑, **不在停用范围**。**legacy static 静默迁移(D8)**: 读到 `ptac_skin='static'` 时归一渲染为变色、动效开关初始化为关(文案「静态」), GM 原值(`ptac_skin` 与 `ptac_motion`)一律不回写, 下次用户手动切换才覆盖, 不加迁移提示。切皮肤/切靠边不重置动效开关, 切动效也不重置皮肤/靠边。
- **FAB 靠边模式(2026.11.24.4, 与皮肤正交)**: 皮肤条内加独立布尔开关 `data-edge`(文案「靠边/展开」, 不参与 `data-skin` 单选、切换不重置皮肤), 存新 GM 键 `ptac_edge` **跨站生效**; 开启后右下角 FAB 变为**静态竖线**(`.edge`: `right:20px; bottom:20px; width:4px; height:120px` 向上延伸, **颜色复用当前皮肤的状态色语义**不另立规则, 不带数字角标, 透明命中区扩至约 24px); hover / focus-within 时就地向左侧展开为原 52px 圆钮, `right`/`bottom` 双锚点不变(不跳位), 面板 `bottom:84px` 定位在竖线态不漂移。**四条件状态机**: ①面板打开期间保持展开; ②关闭面板且指针移出才缩回; ③`batchActive()` 期间强制不缩回; ④触屏两段式(首次点竖线只展开、再点才开面板) + 键盘焦点落入竖线即展开。六场景真浏览器实测见 `calibration-detail.md` 校准项 23 的 C4 段。
- 批量进行中(发起页)：FAB 旁芯片与面板内进度条显示 `批量 i/n · 正在处理/倒计时`, 可随时停止; **后台任务标签不注入 FAB/UI**(避免后台闪烁); 中断恢复横幅已随断点续签机制移除(2026.11.16) —— 中断后任意匹配页清死任务按普通访问处理, 不再弹面板。
- **站点图标**: 每个站点名前显示其 favicon(14px 圆角, 透明底加灰底容错)。取用链 = 配置 `favicon` 字段 → GM 路过收集的真实 `<link rel="icon">` URL(存 `ptac_favicon_<unitId>`, 仅 http(s)) → 站点根 `/favicon.ico` → 无则不发图; URL 与站页面一致时命中浏览器 HTTP 缓存(零额外流量); 加载失败(无图标/路径非标/防外链)由**捕获阶段 error 事件委托**隐藏, 不占位不影响站名。
- **点击站点名** → `GM_openInTab` 新标签(前台)打开该站(行尾 ↗ 提示, 事件委托, 行内容重建不影响)。
- **失败且冷却中的站**(今日 `failed` + 10min 冷却未过): 整行降透明度 + 左侧琥珀竖条 + 副文案提示「冷却中, 默认不参与批量」; 批量候选**默认排除**此类站。常规「批量签到」按钮**右侧紧贴一个窄 chevron 图标钮**(拆分按钮组, 同色系+细分隔线) → 点击后琥珀色的 **「强制批量签到(n 站)」** 按钮从**按钮行上方浮出**(absolute 浮层不占文档流, 覆盖站点列表底部; 按钮与「批量签到」本体对齐), 浮出钮带详细 tooltip; 点击无视冷却强制重试(点击前仍重写冷却, 再失败进入新一轮冷却)。**全部签到完毕(无失败冷却站)或批量进行中隐藏图标钮**(此时「批量签到」恢复完整圆角); 图标钮 hover/展开态变琥珀色(图标不旋转); 强制按钮 tooltip 说明适用场景与风控风险。**行内重试入口(.28)**: 今日失败站的 badge 悬停变琥珀「↻ 重试」(cursor pointer + 风控 title 提示), 点击 → 前台新标签 `?ptacRetry=<uid>` 单站强制重试(无视冷却、完成不关标签; 一次性剥参 + 30s 跨标签互斥锁防并发; 与批量调度互斥)。
- 面板数据读 GM 存储, 任何已匹配站打开均为同一份(满足「任意已添加网站查看完成面板」)。**靠边态与动效开关同样存 GM 键 `ptac_edge` / `ptac_motion` 跨站生效** —— A 站开启靠边 / 关动效后, B 站加载即为竖线态 / 无动效。
