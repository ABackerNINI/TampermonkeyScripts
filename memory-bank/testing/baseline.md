# 测试基线口径(单点)

> 摘要: 基线切片的命名/体例/差值口径 —— 测试基线数字只写 baselines/ 最新切片这一处, 其余一律引用不手抄
> 触发: 立基线, 查基线口径, 对比测试数字

## 口径

1. **数字只写一处**: 全量测试的权威数字(TOTAL/通过/失败/汇总行)只出现在 `memory-bank/testing/baselines/` **最新切片**的「验收数字」节; 其余任何文档(任务档案/切片/issue/计划正文)一律写「全绿(见 kb.baseline)」式引用 + 指向切片, **不手抄数字** —— 判据族 B 拦新增的手抄数字。
2. **更新时机**: 涉码轮收尾 DoD —— `commands run test.full` 跑完后 `commands run kb.new baseline <slug> --title .. --total <实测>`, 数字从实测输出誊写(裁定 A4, 命令不编造); 纯文档轮不立新基线。
3. **命名与体例**: 文件名 = kb.new 派生的 `<YY-MM-DD-HHMM>-<slug>.md`(slug = 专题短键, 如 `test`); 骨架两节固定: 「验收数字」(TOTAL 表 + 汇总行 + 失败项定性)与「本改动面」(逐文件一行); 不在切片正文重复口径样板。
4. **差值口径**: 对比两份基线看 TOTAL 与失败清单的变化; 失败项必须在「验收数字」里当场定性(回归 / 已入池 issue 的既有红 / 环境性 SKIP), 不留「为什么红」悬案。既有红(已入池)不阻断新基线生效, 但**新增**失败必须先处置(修或入池)再立基线。
5. **查询**: `commands run kb.baseline` 列全部切片(时间/slug/摘要), `--check` 校验目录与切片体例; `kb.baseline` 是唯一权威查询口, 不另造清单。
