# `forEach` 回调中 `return []` / `return {}` 无意义
> 摘要: `forEach` 回调里 `return []` / `return {}` 不中断迭代，看似跳过实则无效。
> 触发: 写行校验, 重构 forEach, 排查跳过逻辑

- **触发**: 在 `forEach` 回调中写 `return [];`（行校验失败时）想跳过某行。
- **判别**: 看似"跳过"了某行，实则只是返回了个被忽略的值，行仍继续往下执行（或产生困惑）；`forEach` 忽略回调返回值。
- **处置**: 需要中断当次迭代用 `return;`；需要中断整个循环改用 `for...of` + `break`。

## P4. `forEach` 回调中 `return []` / `return {}` 无意义

**正确做法**：需要中断当次迭代用 `return;`；需要中断整个循环改用 `for...of` + `break`。
