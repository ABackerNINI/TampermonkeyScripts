# hover 展开的菜单/卡片站(如 Railgun 头像用户卡): 程序化 click 无效, 必须派发 mouseenter(或加开合类)再点内层入口
> 摘要: 卡片/菜单由 mouseenter 监听加 `.is-open` 类展开、按钮未注册 click 时, 程序化 click 完全无效; 自动化要先派发 mouseenter 走站点自身逻辑(兜底直接加开合类), 内层入口可见后再点。
> 触发: 站点改版签到入口进弹层, 排查点击无效, 适配 hover 展开菜单

- **触发**: Railgun(bilibili.download)2026.11.19 改版, 签到入口从页面直挂 attendance 链接收进头像用户卡 `.nx-user-card`。实测站点 topbar.js: 卡片开合 = `.nx-avatar-wrap` 上的 `mouseenter` 监听加 `.is-open` 类(mouseleave 后 220ms 延迟移除), **头像按钮未注册任何 click 切换**; topbar.css 三条展示路径 `.is-open` / `:hover` / `:focus-within`。
- **判别**: 与 HHCLUB 的头像菜单不同 —— HHCLUB 点头像是 toggle(click 奇数次开), 程序化 click 有效; 这类站点自动化老思路「先点外层按钮再点内层入口」会静默失效(不报错, 只是卡片根本不展开), 内层入口常驻 DOM 但 display:none → 引擎 `waitForElement` 的 `isInteractable`(getClientRects>0)判不可交互 → click_checkin 等到超时, 日志为 `等待元素 "…" 超时 (元素已存在但不可交互/隐藏) (…ms)` —— **「已存在但不可交互」正指向入口藏在未展开弹层**(引擎刻意区分「不存在」与「存在但不可交互」供排障, 见 src waitForElement 超时分支)。识别方法: 读站点展开逻辑 JS(如 topbar.js), 看开合是 click toggle 还是 mouseenter/hover。
- **处置**: steps 首步用 `{type:'function'}`(照 HHCLUB 点-验-重试骨架): ①对**容器**(不是按钮)派发 `wrap.dispatchEvent(new MouseEvent('mouseenter'))` 走站点自身逻辑(它自己管理类与收起定时); ②兜底: 事件未生效(框架未加载/被拦)时 `if (!wrap.classList.contains('is-open')) wrap.classList.add('is-open')` 直接按 CSS 展示路径开卡; ③验证用内层入口可见谓词(`a[href*="attendance.php"]` 的 getClientRects>0)轮询而非信 aria-expanded(本站头像按钮的 aria-expanded 无人同步); ④不派发 mouseleave —— 站点 220ms 延迟收起不会触发, 卡片保持展开; 点击内层链接(target 在容器内)也不会命中站点 document 级「点外部收起」处理器。**结构与注意节口径统一(2026.11.19.3 起)**: ①-④ 所述展开动作与点击必须**同在一个 function 步内原子完成**(展开→轮询可见→`guardCheckInEntry` 守卫→立即点击, 失败重展开重试), 不再拆「展开步 + CLICK_CHECK_IN」两步 —— 跨步骤间隙内站点可能收起卡片, 见注意节。**文案陷阱**: 改版后横幅文案常去方括号(旧直挂链接 `[签到得魔力]` → 新横幅 `签到得魔力`), `checkInContent` 是子串匹配, 带括号会匹配不中直接不点。
- **注意**: 已签态弹层形态常无样本(未签态保存的页面看不出已签时长啥样), 不要在无样本时猜 — Railgun 2026.11.19 实证: 旧口径「签到已得」真站匹配不中导致已签检测恒失败, 真站样本校准为「今日已签到」并补落地标记, 详见 P33; 若真站确认已签后横幅消失, 再考虑 `noButtonMeansCheckedIn` 语义(见 P31)。另: **hover 展开型站点禁用「展开步 + 点击步」两步流程**(2026.11.19-0618 实证): 展开态不保证跨步骤保持(被动模式用户真实鼠标移开 → 站点 mouseleave 220ms 收起), 次步等横幅可交互会超时记 unconfirmed 而点击未发生 — 必须**原子化**: 展开→轮询横幅可见→守卫→点击合为单个 function 步(引擎 `func(unit)` 可返回 `{alreadyHit}/{refused}` 标记复用 `guardCheckInEntry` 三重守卫), 失败重展开重试; Railgun 已按此修(2026.11.19.3)。
