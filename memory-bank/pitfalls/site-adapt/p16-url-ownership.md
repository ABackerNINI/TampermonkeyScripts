# 页面归属判定: match 已删, url 推导语义要记牢
> 摘要: `match` 已删、归属由 `url` 推导，url 是唯一事实来源。
> 触发: 新增改站入口, 排查不归属, 写 match, 改 url

- **触发**: 所有 unit 不再写 `match`, `matchUnit` 显式 `match`(正则/函数)优先、缺省由 `url` 推导。
- **判别**: 推导规则：host 相等(**忽略 `www.` 前缀差异**), 且 url 带 query 时**逐参数一致(页面可带额外参数)**；写错 url(如漏 `www.` 或画蛇添足加 `www.`)会直接导致页面不归属或错归属。
- **处置**: url 是归属唯一事实来源——新增/改站入口时只改 `url`, **不要**再手写 `match`(除非特例: 多入口 host/跨域归属页)；url 带 query 的站(如贴吧 `f?kw=pt`)判定会检查 query, 页面换参数(如 `kw=pt&pn=1`)仍命中；无 query 的站忽略页面一切参数——后台任务 URL 追加的 `ptacTask` 不会影响归属；`match` 保留为可选项, 特例站仍可用函数细控(如按页面内容归属)。

## P16. 页面归属判定: match 已删, url 推导语义要记牢

**现状**：所有 unit 不再写 `match`, `matchUnit` 显式 `match`(正则/函数)优先、缺省由 `url` 推导。推导规则：host 相等(**忽略 `www.` 前缀差异**), 且 url 带 query 时**逐参数一致(页面可带额外参数)**。
**注意**：
- url 是归属唯一事实来源——新增/改站入口时只改 `url`, **不要**再手写 `match`(除非特例: 多入口 host/跨域归属页); 写错 url(如漏 `www.` 或画蛇添足加 `www.`)会直接导致页面不归属或错归属。
- url 带 query 的站(如贴吧 `f?kw=pt`)判定会检查 query, 页面换参数(如 `kw=pt&pn=1`)仍命中; 无 query 的站忽略页面一切参数——后台任务 URL 追加的 `ptacTask` 不会影响归属。
- `match` 保留为可选项, 特例站仍可用函数细控(如按页面内容归属)。
