> 触发: 不屏蔽未知元素, 四类屏蔽通道, hit-test, 对比度阈值 40, 反例逐个跑

- **触发**: 2026-09-20 用户诉求要保证主题不屏蔽未知元素（消息弹窗 / 公告 / 站点新增的种子标签）；先去数 `display:none` 是没用的 —— 全脚本只有 3 条对外隐藏声明（两个 `<br>` + 搜索箱折叠小图标），真正的风险全在「元素还在、矩形非零、人却看不见」的通道里，这四类此前一条测试都没有。

## P66. 「看不见」不等于「display:none」—— 四类隐蔽的屏蔽通道

**背景**(2026-09-20 用户诉求): 要保证主题**不屏蔽未知元素**(消息弹窗 / 公告 / 站点新增的种子标签)。
先去数 `display:none` 是没用的 —— 全脚本只有 3 条对外隐藏声明(两个 `<br>` + 搜索箱折叠小图标),
真正的风险全在"元素还在、矩形非零、人却看不见"的通道里。这四类**此前一条测试都没有**:

| 通道 | 机理 | 触发条件 |
|------|------|----------|
| 图标被清成空白 | `background-image:none !important` 之后没有补任何 content | 站点新增 `pro_*` / `c_*` 家族(枚举清单里没有) |
| 前景色没管 | 主题只压深**背景**, 不管站点**写死的前景色** | 公告块 `<font color="#000000">`、`style="...;color:#000"` |
| 继承到站点黑字 | 站点 `table.torrents{...color:#000}`, 主题没重置 | 种子表里**任何没有显式上色**的新元素 |
| contain / overflow / z-index | 改定位基准、裁掉溢出、压住浮层 | 表内 `position:fixed` 弹窗、格内新角标、低 z-index 浮层 |

**实测抓到的两条真 Bug**(都是被新用例 `sim-hdui-unknown-canary` 逼出来的):
1. **`table.torrents{color:#000}` 从未被重置** —— 主题只写了 `background/border/padding`。
   已上色的元素(标题链接 / 数值列 / `td[data-hdui-prog]` / `font.color_*`)都是**自己的声明**, 所以一直没暴露;
   但站点将来在种子表里加的任何新徽章都会**继承到纯黑**, 压在深色片基上就是隐形。
   修: `#torrenttable{...color:var(--hdui-fg);}`(继承值压不过直接声明, 不伤既有着色)。
2. **促销徽章没有兜底** —— `PRO_BADGES` 是**按名枚举**的, 而 filmCss 有一条通配的
   `#torrenttable img[class*="pro_"]{width:16px;height:16px;background:none;}` 只清底不换图。
   站点新增的 `pro_xxx` 于是变成 16×16 的空白/雪碧图碎片。修: 在枚举之前补一条兜底
   (`iconUri('medal', PRO_FALLBACK_COLOR)`), 与类别图标同一套纪律(**兜底必须排在具体家族之前**)。

**教训**:
1. **"屏蔽"的判据不能只看 DOM 与矩形** —— 必须加上 hit-test(防被裁/被压)、对比度(防隐形)、
   图标 content/background 至少一层是内联 SVG(防空白)三道。
2. **阈值取 40 而不是 20**: 纯黑(亮度 0)压在片基(亮度 22)上亮度差正好 22 ——
   取 20 会把它判成"合格", 而它正是最典型的软屏蔽。与真站对比度扫描同一口径。
3. **反例必须逐个跑**: 写完全部断言后, 把每条生产兜底删掉一次, 确认对应的断言真的会变红。
   本轮 8 条反例里有 2 条一开始是绿的(判据写得太松), 就是靠反例发现的。
