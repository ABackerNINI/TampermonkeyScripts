# `evenodd` 镂空子路径必须完全落在主体内，否则会越界填出杂形
> 摘要: `evenodd` 镂空子路径必须完全落在主体内，否则会越界填出杂形。
> 触发: 加 evenodd 镂空, 排查主体外杂色小块, 排查子路径重叠

- **触发**: 加了镂空后，主体**外面**冒出奇怪的小色块。
- **判别**: `evenodd` 的规则是"射线穿过路径段数为奇数则填充"；子路径若有一部分在主体外，那部分就会被当作独立区域**填实**，而不是挖空；多个子路径互相重叠时，重叠区会变回填充（3 次穿越 = 奇数）。
- **处置**: 1. 镂空子路径的**所有点**都必须落在主体内部（保守做法：放在主体最宽最厚处）；2. 多个镂空子路径**不能互相重叠**。**排查**：渲染后如果主体外出现杂色小块，第一怀疑就是子路径越界。
