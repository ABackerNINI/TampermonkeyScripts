## P64. 「此刻可见」的扫描抓不到 **hover 态 / 隐藏态** 的元素 —— 要主动按选择器查

**起因**：加了「中间带亮块」扫描（背景 lum 60~200，补 P63 的盲区）后，扫出
`div.niceTitle[domTT__autoId1]` —— 站点 **DomTT 提示框**，背景 `#7c98ae`（亮蓝灰）+ 黑字。

**为什么之前所有扫描都没发现**：它平时是 `visibility:hidden`（`opacity:0`），
hover 才显示。而漏白 / 小件近白 / 对比度 / 文本截断**全都是「扫此刻可见的元素」**
⇒ 隐藏的元素永远不在视野里，但它**一 hover 就在深色底上亮一块**。

**修法**：深色化 `div.niceTitle` 和 `div.smilies td`（论坛表情面板，同一个 `#7c98ae`）。

**教训（重要）**：
- **渲染扫描的覆盖面 = "此刻可见"**，hover 态 / 弹层 / 提示框 / 折叠面板 **一律测不到**。
- 这类元素只能**主动按选择器查**：在真站上 `querySelector` 出来，直接读它的
  `background-color` / `color`（哪怕它此刻是 hidden），判断有没有被主题覆盖。
- 判据：读到的是**站点原色**（`#7c98ae` 这类）就说明漏了；读到主题色（`rgb(25,21,18)`）才对。

**白名单要写清理由**，否则每次扫描都报：
- `span.tags` 的 23 种分类色 —— TASK019 用户拍板**刻意保留**（深色底上唯一彩色元素）
- 主题金 `rgb(245,179,66)` —— 当前页高亮 / 做种数这类**刻意的强调色**
