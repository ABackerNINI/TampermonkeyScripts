# **压平站点底色前, 先问"这个底色在区分什么"** —— P23 的第二次复发
> 摘要: 压平站点底色前，先问「这个底色在区分什么」—— P23 的第二次复发；站点本来用两个不同底色区分置顶区1/区2，.28 为让粉白不刺眼把它们一律压成片基色才抹掉界线，是「修 A 时制造 B」。
> 触发: 压平底色, 信息销毁, P23 复发, 色相补层级, hover 档

- **触发**: 用户报「无法分辨置顶区1 / 置顶区2 / 普通区」；发探针量真站 101 行：表头(0) / 置顶区1(1-41, 无 inline, 站点底色 `#bad6f4` 浅蓝) / 置顶区2(42-50, inline `background-color: rgb(250, 238, 244);` 粉白) / 普通区(51-100) ⇒ 站点本来就用两个不同底色区分两区。
- **判别**: 是 `.28` 为了让粉白不刺眼、把它们一律压成片基色，才把区1/区2 的界线抹掉了 —— 也就是「我在修 A 的时候制造了 B」；这是 P23 的同型复发（P23 是「站点用底色区分做种/下载，被 `[bgcolor]` 压平成同一个深色」，这次是「站点用底色区分置顶区1/区2，被我压平成同一个深色」）—— 同一个动作犯了两次。
- **处置**: 三条纪律：① 压平/覆盖站点底色不是「顺手的事」，它是信息销毁操作，动手前先查这个底色在区分几种状态、压平后靠什么补回（P23 靠文字色补回，这次靠色相补回 —— 两区亮度刻意做成接近，用金调/青绿调区分，这样「置顶比普通亮一档」的层级还在）；② 深浅不够用时用色相补层级（只靠亮度递进档位一多就分不出来，亮度管「层级」置顶 > 普通、色相管「类别」区1 ≠ 区2，两者分工）；③ hover 档要单独给不能复用普通行的 hover 色（本例 `--hdui-rule` 亮度 37 低于区1 39 / 区2 41 ⇒ 悬停反而变暗看着像「按下去」，每个自定义底色都要配一个更亮的 hover 档，断言里用 lum(hover) > lum(base) + 5 钉死）；仿真探针的坑（harness 层）：`page.eval(expression)` 会把表达式包进 `(() => { ... })()`，所以探针里不能再套一层 IIFE —— 套了以后 `return out` 只回到内层函数，外层拿到 `undefined`（表现为 `Cannot read properties of undefined`），探针写成一串语句 + `return` 即可。

## P77. **压平站点底色前, 先问"这个底色在区分什么"** —— P23 的第二次复发

**怎么发现的**: 用户报「无法分辨置顶区1 / 置顶区2 / 普通区」。发探针量真站 101 行:
```
表头(0) / 置顶区1(1-41, 无 inline, 站点底色 #bad6f4 浅蓝)
      / 置顶区2(42-50, inline `background-color: rgb(250, 238, 244);` 粉白)
      / 普通区(51-100)
```
⇒ **站点本来就用两个不同底色区分两区**, 是 `.28` 为了让粉白不刺眼、把它们**一律压成片基色**,
才把区1/区2 的界线抹掉了 —— 也就是**我在修 A 的时候制造了 B**。

**这是 P23 的同型复发**: P23 是"站点用底色区分做种/下载, 被 `[bgcolor]` 压平成同一个深色";
这次是"站点用底色区分置顶区1/区2, 被我压平成同一个深色"。**同一个动作犯了两次。**

**三条纪律**:
1. **压平/覆盖站点底色不是"顺手的事", 它是信息销毁操作。** 动手前先查:
   这个底色在区分几种状态? 压平后靠什么补回?(P23 靠文字色补回, 这次靠**色相**补回 ——
   两区亮度刻意做成接近, 用金调/青绿调区分, 这样"置顶比普通亮一档"的层级还在。)
2. **深浅不够用时, 用色相补层级。** 只靠亮度递进, 档位一多就分不出来;
   亮度管"层级"(置顶 > 普通), 色相管"类别"(区1 ≠ 区2), 两者分工。
3. **hover 档要单独给, 不能复用普通行的 hover 色。**
   本例 `--hdui-rule` 亮度 37 **低于** 区1 39 / 区2 41 ⇒ 悬停反而变暗, 看着像"按下去"。
   每个自定义底色都要配一个**更亮**的 hover 档(断言里用 lum(hover) > lum(base) + 5 钉死)。

**仿真探针的坑(harness 层)**: `page.eval(expression)` 会把表达式包进 `(() => { ... })()`,
所以探针里**不能再套一层 IIFE** —— 套了以后 `return out` 只回到内层函数, 外层拿到
`undefined`(表现为 `Cannot read properties of undefined`)。探针写成一串语句 + `return` 即可。
