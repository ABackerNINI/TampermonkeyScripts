# 促销徽章分色：三种促销**同色**＝用户分不出哪个是 Free
> 摘要: 促销徽章分色：三种促销同色（全是金色 `#f5b342`）＝用户分不出哪个是 Free；「元素渲染了」≠「用户看得出」。
> 触发: 促销徽章, 撞色, pro_free, 按语义分色, 可见数探针

- **触发**: .19 用户实拍「种子缺少Free标记」：真站 28 个 `pro_free` 全都渲染了（可见 28、content→SVG 28），但用户坚称「缺少 Free 标记」。
- **判别**: 三种促销徽章全是同一个金色 `#f5b342` —— `pro_free`（免费）/ `pro_50pctdown`（5折）/ `pro_free2up`（免费+双倍上传）长得一模一样，用户没法从一堆金色徽章里认出哪个是 Free。
- **处置**: 按语义分色 —— 免费 = 绿 `#7fb84e`（PT 通行语义）、5折 = 琥珀 `#f5b342`、免费+双倍 = 紫 `#9b7fd4`，判据沿用导航 16 色的同一套（色相/饱和/亮度不能同时接近）；教训「元素渲染了」≠「用户看得出」，以后报「缺标记/缺图标」先查是不是撞色/太小/太像，不要先假设没渲染 —— 用探针量「可见数 / content→SVG 数 / 宽高」就能区分这两种情况。

## P59. 促销徽章分色：三种促销**同色**＝用户分不出哪个是 Free

**症状**（.19 用户实拍「种子缺少Free标记」）：真站 28 个 `pro_free` **全都渲染了**
（可见 28、content→SVG 28），但用户坚称"缺少 Free 标记"。

**根因**：三种促销徽章**全是同一个金色 `#f5b342`** ——
`pro_free`（免费）/ `pro_50pctdown`（5折）/ `pro_free2up`（免费+双倍上传）长得一模一样，
用户没法从一堆金色徽章里认出哪个是 Free。

**修法**：按语义分色 —— 免费 = 绿 `#7fb84e`（PT 通行语义）、5折 = 琥珀 `#f5b342`、
免费+双倍 = 紫 `#9b7fd4`。判据沿用导航 16 色的同一套（色相/饱和/亮度不能同时接近）。

**教训**：**"元素渲染了" ≠ "用户看得出"**。以后报"缺标记/缺图标"先查**是不是撞色/太小/太像**，
不要先假设没渲染 —— 用探针量「可见数 / content→SVG 数 / 宽高」就能区分这两种情况。
