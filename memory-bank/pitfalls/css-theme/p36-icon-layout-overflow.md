# 图标"没显示"可能是被布局吃掉：列宽溢出 + `overflow:hidden`
> 摘要: 图标「没显示」可能是被布局吃掉：列宽溢出 + `overflow:hidden`。
> 触发: 排查单列图标不显示, 改列宽, 排查 wiring

- **触发**: 某一列的图标死活不出现，但 CSS 选择器、data URI 全都正确；其它列都正常。
- **判别**: 该列宽 44px，而 `img(16) + gap(5) + 文字(~28) ≈ 49px` → **溢出 5px**，单元格 `overflow:hidden` 把左侧的图标整个裁掉，文字仍在（所以看起来"只有文字"）。**判定口诀**：**单列图标缺失，先量列宽，别改图标设计。** **验证手段**：把该列的 `content` 临时换成一个 22×22 实心方块再截图 —— 如果哈希仍无变化，证明 wiring 没问题，是布局把图标吃了。
- **处置**: 给该列加 10px 余量（44 → 54）。其它列若宽度 < 60px 也应复查。
