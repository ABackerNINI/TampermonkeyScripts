# 16px 小图标设计: 只有三类信号能幸存, 细节一律消失
> 摘要: 16px 小图标设计：只有三类信号能幸存，细节一律消失。
> 触发: 设计小图标, 定稿前对照, 排查图标读不出, 改成对概念

- **触发**: 图标在 96px 设计稿上语义清晰，塞进 16px 导航/表头后完全读不出。
- **判别**: 16px 下可用的像素太少，任何"细节"级差异（叶脉、茎的弯折、卷边、渐变）都会被抹平。
- **处置**: **16px 下真正能幸存的只有三类信号**：1. **闭合主体的明显缺口 / 孔洞**（`evenodd` 镂空或直接拼进路径的咬口）；2. **方向显著变化**（倒置、倾斜、掉落）；3. **配件显著**（碎屑、掉落物、附加形状）。成对概念（活/死、整/缺、开/关）**保留同一轮廓 + 只改强信号**，不要发明新形状。**流程铁律**：任何新图标 **先做 4 尺寸对照 sheet（96 / 48 / 24 / 16 同屏）再定稿**，绝不要在单一尺寸上反复微调 —— 看不到全局就会陷入一轮轮返工。

## P34. 16px 小图标设计: 只有三类信号能幸存, 细节一律消失

**症状**：图标在 96px 设计稿上语义清晰，塞进 16px 导航/表头后完全读不出。
**为什么会发生**：16px 下可用的像素太少，任何"细节"级差异（叶脉、茎的弯折、卷边、渐变）都会被抹平。
**16px 下真正能幸存的只有三类信号**：
1. **闭合主体的明显缺口 / 孔洞**（`evenodd` 镂空或直接拼进路径的咬口）
2. **方向显著变化**（倒置、倾斜、掉落）
3. **配件显著**（碎屑、掉落物、附加形状）
**推论 —— 成对概念（活/死、整/缺、开/关）的正确做法**：
**保留同一轮廓 + 只改强信号**，不要发明新形状。"完整 vs 残缺" 是世界上最直白的对照，
远比"换个隐喻但形状完全不同"好认。
**流程铁律**：任何新图标 **先做 4 尺寸对照 sheet（96 / 48 / 24 / 16 同屏）再定稿**，
绝不要在单一尺寸上反复微调 —— 看不到全局就会陷入一轮轮返工。
