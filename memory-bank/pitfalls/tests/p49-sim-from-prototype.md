## P49. 仿真剧本从「原型」派生 ⇒ 全绿但真站画错（**全绿只证明没回归**）

**症状**：`node tests/run-all.js` **26/26 全绿**，真站上却有一整批样式没生效（P48）。

**为什么**：
```
原型 film.html ──移植──▶ src/HDHomeUI.user.js
      │                        ▲
      └──照抄简化版──▶ tests/lib/sim/hdhome-ui-page.js ──断言──┘
                        ✗ 没有一条线连到真站
```
仿真页是**照原型写的简化副本**（类别只用那 7 个家族、标签用 `tfree`、标题格只有 2 格、
站点 CSS 只有 `background`），于是"原型 → 脚本 → 仿真"三者自洽，**唯独与真站脱节**。

**纪律**：
1. **仿真剧本必须从真站脱敏页派生**（只保留 class / 结构 / 站点 CSS，凭据一律 `***`），
   不能从设计原型派生。
2. **仿真页的 `SITE_CSS` 必须是真站 CSS 的子集，不能是"大概像"** ——
   缺一条真站规则就等于给脚本留一个测不到的盲区。
3. **先改仿真、再看变红**：把仿真页补齐成真站子集后，测试应当**大面积变红**；
   逐条与差异清单对账（对不上的说明还有没发现的差异），然后再修脚本。
4. **换肤/样式类脚本的验收必须包含"真站脱敏页离线渲染 + 与原型并排截图"**，光跑仿真不算数。
5. **结论**：**"仿真全绿"只证明没有回归，不证明真站画得对。**

**配套的仿真基建坑**：站点剧本对未知路径是**兜底渲染整页 HTML** 的。
把 HTML 当成图片响应（`/static/*.gif` 之类），`<img>` 就是"加载失败" ——
浏览器改用 **alt 文字**排版，一个 16px 的图标会变成 83px 宽（"download" 那串字），
布局与几何断言全被带偏。**静态资源必须在渲染剧本之前拦下来，返回能解码的 1×1 透明图**。
