§01目标与设计原则

目标 — 修补已实施版暴露的四个偏差：① 「静态皮肤」改为正交于皮肤的「关闭动效」布尔开关，皮肤条回归「变色 / 信号灯」2 项；② 靠边竖线真贴右边缘（right:0，bottom:20 与按钮水平对齐）；③ 根治 hover 临界区闪烁；④ 关动效 / 靠边两态下，UI 静息 CPU 降到 0（仅计 UI 更新，不计签到逻辑）。成态判据：静态断言 + CDP 5s 静息录制零 FAB 归因重绘，四项各带验收。

不变量（硬约束）:

  1. 本轮零实施 — 本篇是计划；不改代码、不入池 issue、不认领、不 commit/push。实施须用户逐项授权（新建文件 / 入池 / 认领 / commit 四类动作分别确认）。
  2. 签到逻辑零改动 — 签到、批量、冷却、重试、favicon、状态判定一律不碰；ptacHlPulse（第 3137 行，签到按钮高亮脉冲）按 Q1 保留，属签到逻辑不计入 UI 动效开关范围。
  3. 正交语义延续 — 动效开关、靠边开关都与皮肤单选正交；切皮肤不重置两开关，GM 值各自独立持久化；靠边竖线颜色仍复用当前皮肤状态色语义（P17）。
  4. 静默迁移 — 旧 ptac_skin='static' 纳入 legacy 归一为变色（渲染+高亮一致），并把动效开关初始化为关；GM 值原样保留不回写（与 D4 一致，不加迁移提示）。
  5. 版本与知识库同步 — 实施轮每批改脚本必须同批递增 @version 并回写 memory-bank/ 受影响条目（fab-ui.md / overview.md / P17 / known-issues.md / README）；本批只写方案文档不触发。
  6. 测试护栏 — test.full 全绿；静态断言 + 仿真用例随实现同批落地；基线数字只写 testing/baselines/ 新切片。

取舍口径（源自 grilling）：闪烁走根因修法（统一命中区 + pointermove 实测），明确放弃时间锁权宜；靠边展开按用户选择「内移 20px 回原位」，接受一次可控跳位换取贴边 + 原视觉位置双满足；静息口径只管静止不动时，形变 transition 属交互响应不算静息负载。

§02现状与痛点

实施版 src/PTAutoCheckIn.user.js @version 2026.11.24.4 的四个偏差，均有代码对应（行号可复跑）：

偏差代码现状（证据）为何是问题
① 静态做成皮肤皮肤条第 2658 行 data-skin="static"；.fab.static 第 2267-2268 行禁动画；皮肤变量第 2549 行含 static用户要的是「关闭动效」开关（正交于皮肤），不是第三种皮肤；静态=变色静态版使皮肤条语义与动效控制耦合
② 靠边未真贴边.fab.edge 第 2273-2274 行 right:20px; bottom:20px离右边缘 20px，不是"真靠边"；用户要紧贴右边缘
③ 临界区闪烁命中区 ::before 第 2281-2284 行固定 left:-20px; width:24px; height:140px（竖线尺寸）；展开态第 2292-2305 行形变到 52px 但命中区不随之变；edgeHover 由 mouseenter/leave（第 2739-2740 行）驱动命中区按竖线尺寸固定，展开后视觉边界（52px 宽）超出命中区；指针在展开态左半边缘时 mouseleave 缩回、缩回后命中区又覆盖指针触发 mouseenter，形成反复翻转 = 用户报的闪烁
④ 静息 CPU 未归零关动效有 static 皮肤路径，但「靠边 + 动效开」组合下 .fab.edge 第 2275 行虽 animation:none，皮肤条切 stateless 后仍可能挂 baseGlow（第 2219 行 ::after）；且无 CDP 实证口径没有独立的动效开关保证"关了就是 0"，也没有 CPU=0 的可验判据

补充事实：脚本当前 infinite 动画共 4 类 —— baseGlow（2219）、stateGlow（2245）、chameleonWave（2255-2256）、ptacHlPulse（3137，签到按钮高亮，Q1 判定保留）。定时器最短 200ms（1863、3020），无毫秒级循环。

§03方案总览

主线一句话 — 把"静态"从皮肤枚举里拿出来做成正交的「关闭动效」布尔开关（与靠边开关并列），靠边竖线改 right:0 真贴边并把命中区/指针判定一并根治闪烁，最后用静态断言 + CDP 静息实测把"UI 静息 CPU=0"钉成可验判据。

§07风险与对策

风险触发条件处置
展开内移 20px 的跳位观感hover 时 right 从 0→20 是位移，与宽高形变叠加可能显得"先跳再变"把 right 纳入同一条 transition（与 width/height/border-radius 同时长同曲线），让位移与形变同步发生；仿真断言形变起止几何
elementFromPoint 在 closed shadow 的命中判定指针在竖线/展开圆钮上时 elementFromPoint 返回 host（#ptac-root-v2）而非 fab 本身沿用面板自动关闭的同款 shadow 重定向（fab-ui.md 校准项 23）：host.contains 判定命中；仿真覆盖竖线/展开/面板重叠区
命中区并集过大遮挡页面点击并集宽 52px 向左外扩覆盖页面内容，拦截站点按钮点击命中区 pointer-events 仅设在透明伪元素且与 fab 可视区对齐；仿真验证并集区外页面按钮可正常点击
动效开关与靠边态组合的状态色关动效后靠边竖线是否仍随状态色更新动效开关只禁 animation，不碰 applyFabSkin 的 class/角标/状态色逻辑；组合态单独仿真一例
CDP 实测环境不可用无浏览器/无 CDP 连接静态断言仍进 test.full；CDP 用例按项目约定 SKIP 并在基线切片注明环境理由，不伪造数字
旧 static 用户升级的 MV 值不一致skin='static' 归一变色后动效开关初始化为关，但 GM 仍存 static按 D8 接受：GM 原值保留不回写；下次用户手动切换皮肤/动效才覆盖，文档钉死
